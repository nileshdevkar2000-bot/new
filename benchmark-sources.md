# NEO benchmark sources (public product patterns)

These are reference sources used to shape NEO's architecture. NEO does not copy third-party UI, source code or proprietary text.

## Quri AI — Clinical intelligence
https://quri.ai/
https://www.quri.ai/forsponsors
https://www.quri.ai/terms-of-service
Pattern used: study intelligence, site/search intelligence, feasibility workflow, source aggregation, pipeline/task tracking, de-identified data emphasis.

## Medidata — Clinical AI
https://www.medidata.com/en/clinical-trial-products/medidata-ai/
https://www.medidata.com/en/clinical-trial-data-with-ai/
Pattern used: study-centric AI layer across the lifecycle, conversational access to platform knowledge, predictive study/site intelligence, connected workflows, formal validation and human-in-the-loop.

## Veeva Safety — Pharmacovigilance
https://www.veeva.com/products/veeva-safety/
https://www.veeva.com/products/veeva-safety-suite/
Pattern used: unified safety lifecycle from intake to reporting, AI-assisted intake/narratives, signal detection, and clinical/quality/regulatory connections.

## Ideagen — Quality Management / Mazlan
https://www.ideagen.com/solutions/quality/quality-management
https://www.ideagen.com/solutions/quality/quality-management/ai-powered-workflow-generation
Pattern used: connected QMS, embedded contextual AI, configurable workflows, auditability, multi-site consistency and explicit human approval.

## ServiceNow — enterprise agent orchestration
https://www.servicenow.com/workflow/enterprise-it/knowledge-2026-through-it-lens.html
https://newsroom.servicenow.com/press-releases/details/2026/ServiceNow-launches-the-real-time-data-foundation-that-puts-autonomous-ai-to-work-across-the-enterprise/default.aspx
Pattern used: cross-functional orchestration, governed workflows, context/data connectivity and control-tower style governance.

## Google Gemini Live — live voice agent
https://ai.google.dev/gemini-api/docs/live-api
https://ai.google.dev/gemini-api/docs/live-api/ephemeral-tokens
Pattern used: low-latency bidirectional audio, interruption handling, live transcription, tool use/search and short-lived client authentication.
